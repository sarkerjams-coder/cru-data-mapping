# Bangladesh Climate Maps (CRU, 2021–2025)

This repository contains climate maps of Bangladesh generated from **CRU (Climatic Research Unit) data** for the period **2021–2025**.

The maps were prepared in GIS using the **Cell Statistics** tool with the **Mean** statistic. For each variable, the mean value was calculated for each raster cell across the available input layers for the 2021–2025 period, producing a spatial representation of the average climate conditions.

## Map Contents

The folder contains the following PNG maps:

|Map|Variable|Description|
|-|-|-|
|Temperature|Mean Temperature|Spatial distribution of mean temperature for 2021–2025|
|Tmax|Maximum Temperature|Spatial distribution of mean maximum temperature for 2021–2025|
|Tmin|Minimum Temperature|Spatial distribution of mean minimum temperature for 2021–2025|
|Precipitation|Precipitation|Spatial distribution of mean precipitation for 2021–2025|

## Methodology

* **Data source:** CRU climate data
* **Period:** 2021–2025
* **Spatial processing:** Raster-based Cell Statistics
* **Statistic used:** Mean
* **Output format:** PNG
* **Study area:** Bangladesh

For each climate variable, the corresponding raster layers covering the 2021–2025 period were combined using the **Mean** option in Cell Statistics. The resulting raster represents the cell-by-cell average across the selected input layers.

## Important Note

The values and units shown on each map follow the corresponding CRU variable and the processing applied to the source raster data. The PNG files are map visualizations for presentation and interpretation; the original raster datasets should be used for numerical analysis and further GIS processing.
